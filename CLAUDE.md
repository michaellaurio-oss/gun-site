## Data model (SQLite)

- **`firearms`** — one row per MODEL (spec catalog). Imperial columns (`*_in`, `*_oz`, `*_lb`) are entered; metric columns (`*_mm`, `*_g`, `*_kg`) are **generated columns** — never insert into them. `category` ∈ handgun / rifle / shotgun / other (other = receivers, build kits). `description` = marketing blurb (model-level). `data_notes` = sourcing notes, conflicts, "placeholder caliber" flags. `source_url` = where specs came from.
- **`listings`** — one row per PHYSICAL gun for sale, `firearm_id` → firearms. Key fields: `stock_number` (unique; optional only while status is draft/coming_soon — enforced by CHECK), `status`, `price_usd`, `condition` (New, Like New, Excellent, Very Good, Good, Fair, Poor), `condition_notes`, `est_round_count`, `finish_color`, `modifications`, `magazines_included`, `original_box`, `included_items`, `description` (per-gun), `additional_comments` (public), `internal_notes` (**private – never render**), `listed_at`, `sold_at`, `sold_price_usd`.
- **California:** `firearms.ca_rostered` (1 = on the current CA DOJ Handgun Roster, 0 = off roster, NULL = not yet checked / long gun) + `ca_roster_checked_on` date. The roster lists specific models, so it lives on the model. Currently NULL for every model — needs checking against the DOJ roster (oag.ca.gov/firearms/certified-handguns). Per the owner: off-roster handguns that are properly registered in CA can be sold USED, by the dealer or via private-party transfer — so used off-roster handguns are listed normally. A NEW handgun generally must be on the roster for a dealer to sell it.
- **New vs used:** `listings.new_used` ∈ new / used (default used). New guns should use condition "New".
- **Roster safety check (triggers):** the DB rejects a NEW listing for a handgun model with `ca_rostered = 0`, and rejects setting a model off-roster while it has active new listings. Used off-roster handguns are allowed.
- **Consignment:** `listings.consignment` (0/1, default 0). No filter (owner's decision). How/whether to show it publicly is not decided yet — ask Michael.
- **Magazine capacity:** wherever factory capacity over 10 is shown (cards, detail facts, spec table), append "(10 round limit in CA)". `listings_public.ca_capacity_note` provides it (NULL when capacity ≤ 10).
- **"Off roster" hover note** (inventory card tag + detail page CA Roster fact): exactly "Not on current CA handgun roster". No further explanation — CA buyers know the rules or will ask the shop.
- **`listing_photos`** — many per listing: `file_path` (e.g. `photos/U-0001/left.jpg` or a URL), `caption`, `sort_order`, `is_primary`. Photos live as files, not in the DB. Michael will supply high-resolution photos of each actual gun.
- **`listings_public`** (view) — what the website reads: listings with status coming_soon / available / on_hold / pending, joined to key model specs + `model_description` + `primary_photo`. Excludes internal_notes.

## Design system (clean & modern)

- Background #F7F6F3, surfaces #FFFFFF, borders #E3E1DC / #D6D3CC, ink #16181A, secondary text #43474C / #5A5E63, photo placeholder #EBE8E2.
- Accent (burnt orange) #B4541A, hover #8F3F12. Primary CTA uses the accent.
- Fonts (Google Fonts): **Archivo** 700/800 for headings & prices, **IBM Plex Sans** for body, **IBM Plex Mono** for spec numbers and stock numbers.
- Content width 1200px (120px side padding at 1440). Radius 8px (controls), 12px (cards), 16px (hero/photos).
- Specs always shown in **both imperial and metric**.
